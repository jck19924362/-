# 浙江教师招聘智能匹配

考教师编的同学用：填一下你的情况，自动告诉你哪些岗位**够得着**。

- 🟢 可报：条件和你都对得上
- 🟠 待定：部分存疑，去公告原文再核
- 🔴 不可报：明显卡住（教资证学段不够、学历不够等）

## 怎么用

1. 打开页面（GitHub Pages 链接）
2. 填学历、户籍地市、教资证学段与学科、荣誉情况
3. 点「匹配」看结果
4. 想只看某学段，点顶部「报考学段聚焦」的 小学 / 初中 / 高中；灰掉的卡片会写清原因

> 结果仅供参考，最终以各地教育局 / 人社局官方公告为准。
