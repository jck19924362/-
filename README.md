# 浙江教师招聘智能匹配（师元版）

考浙江教师编的同学，填一下自己的情况，自动告诉你哪些岗位**够得着**。

本工具由 **浙江师元机构** 整理维护，岗位门槛数据来自浙江各地教育局 / 人社局官方公告，并参考师元发布的教师招聘考情白皮书，帮你把分散、难读的公告条件变成一眼能看的匹配结果。

## 它能帮你做什么

- **一键匹配**：输入学历、户籍地市、就读院校、是否师范类、教资证学段与学科、荣誉奖项（奖学金 / 优秀毕业生 / 竞赛等），立刻算出你能报哪些批次
- **三色结果，原因透明**：
  - 🟢 **可报**：条件和你都对得上
  - 🟠 **待定**：部分存疑，建议去公告原文再核对
  - 🔴 **不可报**：被明显卡住（教资证学段不够、学历不够等），并写清卡在哪
- **报考学段聚焦**：只想看小学 / 初中 / 高中？点顶部按钮只看该学段；灰掉的卡片会写明"为什么不行"（比如差一个初中教资证）
- **不是黑箱**：每条结果都告诉你判定依据，方便你反向核实

## 怎么用

1. 打开页面：https://jck19924362.github.io/shiyuan-teacher-match/
2. 按实际情况填档案 → 点「匹配」看结果
3. 用顶部「报考学段聚焦」缩小范围，灰卡原因一目了然

> 结果仅供参考，最终以各地教育局 / 人社局官方公告为准。
